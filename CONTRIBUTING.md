# Contributing Guidelines

Thank you for contributing to the Collaborative Learning & Project Hub!

## Development Workflow
1. Fork or branch from `main`.
2. Create a descriptive feature branch (`feature/your-feature-name`).
3. Ensure client and server tests/builds pass locally.
4. Open a Pull Request targeting the `main` branch.

## Code Standards
- Keep commits atomic and descriptive.
- Adhere to the established repository structure and REST conventions.
